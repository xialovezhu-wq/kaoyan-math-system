# 考研数学学习系统

围绕考研数学的当前题讲解、完整学习证据保存、错题知识网络、正式入库和旧题复盘构建的本地 Python 系统。高等数学、线性代数、概率论使用统一的证据和版本边界，同时保留不同的知识点与题目身份。

## 运行逻辑

1. 讲题时根据当前知识点读取已有的有界个人摘要；当前题目和实际作答始终决定判断。没有摘要时直接依据当前题目教学。
2. 用户要求保存时，`capture_current_math.py` 按会话身份与精确消息边界保存完整对话、原始附件及已展示的卷面写法，生成不可变 Capture。快速保存不替代正式判分或长期掌握度更新。
3. 网页增强或本地正式编纂根据明确的一组 Capture 产生正式语义，经过身份、原文、哈希和重复写入检查，更新正式题卡与知识点记录。
4. 正式提交后的教学摘要、导航、展示资产、共享发布和归档具有各自回执；失败时恢复缺失步骤，不能重新应用已完成的正式写入。
5. 晨间选题和学习后的旧题筛选是不同入口；复习调度依据真实记录，提示后完成与独立正确分开表示。

## 目录

| 目录 | 用途 |
|---|---|
| `数学一回滚复习系统/scripts/` | Capture、复习调度、旧题队列、展示资产与提交后恢复 |
| `数学一回滚复习系统/schema/` | Capture、回滚同步、展示资产协议 |
| `错题知识网络/scripts/` | 正式卡与知识网络、知识点索引、讲题上下文、网页输入与复盘交接 |
| `错题知识网络/schema/` | 题卡、概念观察、关系规则及模板 |
| `codex-skill-sources/` | 与代码配套的当前技能说明、边界和人工操作合同 |
| `tests/`、`examples/` | 合成测试子集与纯合成结构示例 |

私有运行时通常还包含 `错题知识网络/错题卡/`、`错题知识网络/学习记录/`、`数学一回滚复习系统/快速入库来源/` 等目录。这里仅公开其结构和处理逻辑。

## 环境与入口

建议 Python 3.11 及以上。主要逻辑使用标准库；电子表格导入需要 pandas/openpyxl，PDF 素材处理可用 PyMuPDF。外部 OCR、Obsidian、归档磁盘和共享发布器属于可选的本地集成，仓库没有附带这些运行环境或学习资料。

在仓库根目录可安全查看命令接口：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 数学一回滚复习系统/scripts/capture_current_math.py --help
PYTHONDONTWRITEBYTECODE=1 python3 数学一回滚复习系统/scripts/quick_intake.py --help
PYTHONDONTWRITEBYTECODE=1 python3 错题知识网络/scripts/math_enhancement_input.py --help
PYTHONDONTWRITEBYTECODE=1 python3 错题知识网络/scripts/math_teaching_context.py --help
```

完整运行需要另建自己的私有数据目录，按对应 schema 准备数据，并显式传入目标库和消息来源。`capture_current_math.py --repo` 支持隔离目标库。正式入库、调度与归档需要各自的真实输入和授权；本页只演示接口查看。

## 公开范围与个人数据边界

本仓库从本地学习系统单独导出，只包含通用源码、数据结构、当前工作流合同和少量合成测试。原仓库的 Git 历史没有迁入。

真实题卡、首次作答、完整对话、个人知识点摘要、复习记录、分数、调度状态、Capture 包、原始附件、书籍教材和外部归档均不公开。`examples/` 是本次专门编写的合成结构示例，不能作为真实学习证据提交。

源码中的本机用户路径已改为 `/Users/your-user`；归档磁盘 UUID 改为全零占位；原账号的私有库名称不作为默认远端。涉及 Study-Pro-Bridge、Obsidian、MarginNote、Codex 会话库和外部磁盘的集成功能需要使用者自行配置。不要把真实学习目录直接作为这个公开仓库的工作目录。

公开版未携带个人生产绑定描述符，需要在自己的隔离环境生成对应绑定；历史迁移脚本的个人修复清单已清空，保留通用实现。技能文件是工作流参考，不会自动安装或执行。原系统的旧协议保留用于理解和恢复逻辑，不能替代下文所列当前入口。

## 验证情况

发布准备进行了全部 Python 文件的 `ast.parse` 语法检查、全部 JSON 文件解析、下列入口的 `--help` 检查及 Gitleaks 源码扫描。没有执行真实学习写入、正式入库、归档或云端发布；没有运行需要完整私有库与外部应用的端到端流程。

`tests/` 仅保留已检查为临时目录和合成数据的测试子集；没有宣称完整测试套件通过。

## 公开版的发布边界

本公开副本不默认向原三科完整私库上传。原账号远端已替换为 `YOUR_GITHUB_ACCOUNT` 占位，本机集成路径已替换为 `/Users/your-user`，生产共享发布器和私有运行配置没有打包进入此仓库。上面的 `--help` 命令只显示接口，不执行学习写入或上传。后续若自行接入发布器，须先明确设置自己的目标目录、远端和公开范围；公开源码仓库与真实学习数据目录应分别维护。
