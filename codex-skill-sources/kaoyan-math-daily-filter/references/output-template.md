# 数学学习后筛题报告模板

聊天输出遵守当前 AGENTS.md。这里的标签用普通文本单独占行。

本次范围

说明这是学习后筛题，列出完成小节、日期与 anchor IDs。

最值得复做的已有旧题

每题包含：

1. 正式 ID 与 Obsidian 链接
2. 原题号或来源
3. 最近一次真实学习时间
4. 已做次数与全部日期
5. `exact_gap` 或 `knowledge_fallback`
6. 具体命中证据；fallback 必须写“不代表同一错因”
7. 证据来源和置信度
8. 为什么现在值得复做

排除与缺口

说明 anchors、已掌握和第 0 至第 7 天真实学习活动排除；候选不足时直接写实际数量。关系或 Wiki 维护时间不得冒充学习活动。

只读确认

确认没有修改正式卡、generated、Wiki、视觉层或回滚账本，也没有生成数学题。
