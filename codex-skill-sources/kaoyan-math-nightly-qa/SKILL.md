# 数学正式入库与日终收口

“提交执行今天的正式入库”等日终指令按原学习日完成正式入库和摘要验回、次日高频题单、全天交互复习页。仅要求工程维护、预览、快速保存或指定单项时按该范围执行。已完成部分以原回执续办。

1. 明确日期、截止日或精确 Capture 集合。读取原生 pending/backlog、原对话和附件，复用已有 freeze/closeout。范围、冻结和逐点编纂见[准备合同](references/formal-preparation.md)；跨日按[截止日回放](references/backlog-through-date.md)。用户材料、机器转录、提示后变化与独立首答分别核来源和时序。
2. 只为已冻结且获准的真实学习事实成稿。现有 Embeddings 按内容哈希复用，Decisions 审查实际采用的候选与成稿；锁内唯一 writer 按原 proof 串行写入。题目或概况更正保留原件、前版和适用条件。按[提交、展示资产和恢复](references/commit-and-recovery.md)办理。每个目标包括 unchanged 都先验 math-teaching-context-v1，再办理 math-fast-intake-closeout-v3；不把 closeout ID 填入先决材料。
3. 原身份核对正式卡、展示资产、[T9 原包归档](references/t9-raw-package-archive.md)和指针。正式层已提交时只续失败的后置步骤。索引、向量、个性化概况按[后置读回](references/postcommit-readback.md)核同一版本，protected 保持保护。只读和普通讲题不启动这些维护。
4. 日终用[次日备题](../kaoyan-math-warmup/SKILL.md)与[全天阅读卡片](../kaoyan-math-visual-review/SKILL.md)完成另两项交付。分别报告来源范围、原生事件/维护 ID、可用版本及待办。仅在本次明确要求发布时走原生发布器。

正常原始证据的读取权限与并发规则见[原生读取合同](references/native-luna-read-contract.md)。旧 A 回包、故障组件或专项回退只读取对应参考。
