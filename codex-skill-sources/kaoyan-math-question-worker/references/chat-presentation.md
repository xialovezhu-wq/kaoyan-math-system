# 聊天重点与次重点

用于数学讲解、局部纠偏和讲题回报的自然语言正文。当前会话直接组织和检查回复；无需调用排版程序、生成分析稿或改写题源。代码、命令、结构化数据和逐字引用保留原有内容与格式。原题或来源有笔误时另作说明。

1. 先确定读者本轮要理解、记住或执行的事。有明确待判断的命题时，优先呈现对该命题的直接回答；解题和纠偏优先呈现触发方法的线索、首个关键动作或有证据的断点与修复。会改变真假或适用范围的条件、否定、量词、定义域、单位和推出方向，与相关结论写在同一句内。
2. 实质讲解时，在正文加粗最短但完整的关键判断或动作，决定性的条件、否定、单位和范围留在同一句。小标题用普通文本独占一行、前后留空；用户明确要求放大某句时才使用大字号。公式留在正文。
3. 实质依据、辨析或补充用“【依据】”“【辨析】”“【补充】”引出，包括单独展开的证明。标签可以放在句中或段首，遵循当前聊天排版规则。会改变判断的事实或条件仍按一级强调。背景与串联用普通正文，简短回答可直接衔接。短追问只讲当前步骤；并列用列表，对照才用表格。颜色只用于已确认支持的独立成品，聊天按当前排版规则呈现。
4. 公式沿用聊天原生排版，复杂式独立成块。保留变量、条件和推导方向，强调落在说明文字。矩阵关系用“矩阵｜特征值｜对应的特征向量｜适用条件”，简短关系和条件写在同一行，长推导另列。
5. 发出前核对条件、否定、来源和不确定性是否仍清楚。实质讲解继续按主 Skill 交代已核考频或具体缺口；当前提示权限和真实作答证据决定讲什么。显示重点不改变摘要、保存或掌握度的判定。
