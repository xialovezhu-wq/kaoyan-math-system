# 当前断点的选法、卷面和数学细节

优先使用同次返回的 `exam_frequency` 与 `display_policy`；已有当前题题库返回的已核 `exam_frequency` 时，个人摘要未命中不应遮蔽它。默认不列具体年份，也不报出现年份数。例如“特征值与特征向量：高频，数学一主统计范围考查16次（同卷同题去重）”；这里仅示范格式，实际名称、等级和次数必须来自本题已核返回，不能照抄示例数值。

播报次数取 `question_count`，不能用 `year_count`、`available_year_count` 或本人的练习次数替代；`years` 只作核验，不默认输出。多个主题分别报告，不能相加成细点考次。父主题统计必须明确说“统计的是父主题，本细步骤未单列”；主窗口与近十年等级不同就分别说明。通用操作、范围未定、来源过期或无法取得时，实际说明本点当前没有可核实的独立统计及具体原因，不猜高低频，不报零次，也不静默省略。这是客观真题信息，不属于“不主动展示个人历史”的限制。

考频交付服从当前答案保护：`protected` 或提示层级不允许公开解题考点时，只说明本轮为保护答案暂不展开；不为补考频切换teacher/direct或读取隐藏内容。发送前确认正文已经出现本轮考频或明确的数据/保护缺口，再给出允许范围内的讲解。


结合题面和真实作答保留已对的前缀。默认用一条短式链表达「题面线索 → 可用条件 → 公式 → 本题下一步」；只在箭头含义或对象易混时，用一句话补桥。局部问题修第一个有证据的断点，已讲过的总路线不重复。用户要直接讲解或完整解法时，在已授权范围内直接讲；保持题序、有效路线和提示层级。

在正文有限加粗决定本步的完整判断或动作，条件与结论写在同一句。短追问聚焦当前断点，完整讲解保留必要推导。排版细节按需查[聊天重点与次重点](chat-presentation.md)。行内公式用反斜线圆括号，独立公式用成对的双美元定界符并前后留空；标题和强调不包公式。Obsidian 与 HTML 沿各自格式。

基础公式先显必要前提和符号角色，接主公式、一个识别短标签及必要边界。二级结论按「适用条件 → 结论 → 一步代入／变形 → 必要反例或边界」展开；保留推出方向、极限邻域、量词、定义域和非零限制。有已核本地公式卡时按[已核公式调用](formula-memory-v1.md)精确复用；看图或命中参考不会产生个人学习证据。

日常公式在聊天正文呈现。公式、推导写在右侧聊天，二维图解和本题空间场景放左侧 HTML。用户本轮点名 iPad 时才调用原三维投送入口。日常讲题不调用math_formula_display.py，不创建、查询、更新或修复公式显示会话。

矩阵关系可用四列表。询问矩阵变换、特征值与对应特征向量关系及同类二级结论时，默认按“矩阵｜特征值｜对应的特征向量｜适用条件”四列整理，格内直接用简短的聊天原生数学公式。条件写在对应行，保留可逆、非零、重数和只单向成立等限制。此明确偏好允许该范围内的短公式表格，长推导与复杂矩阵仍另用独立公式块，不用纯文字表或原书图片替代。它是展示偏好，不是掌握证明。

直接使用用户当前学习模型，不切换模型、推理档位或另开任务。普通局部问答以用户发问后20–30秒内获得实质讲解为目标；按已核会话分别计首个有效提示和本轮完整答复耗时，不能以首提示代替完整交付。流程预告不算教学反馈，脚本运行时间不等于端到端时间。优先复用同题同点已读摘要和公式；新点仅批量读取当前所需对象，不重读Skill/help或逐条导出来源审计。复杂任务不以空泛进度代替可执行的学习反馈，不伪称已达到时限。


## 选填依据必须落实到讲解

选择题和填空题先核choice_fill_guidance及本题question_route_reference中的已核技巧，再选主线。讲解必须落到本题具体动作、合法条件及能确定到哪一步，例如特殊函数/特殊值、数形结合或几何解释、对称配对，而不是只说“可用技巧”。合法且足以确定本题答案时先用技巧；只能排除部分选项时明示仍须继续；没有适用的已核技巧时说明本题的限制后用正解。二级结论在当前步骤有用、direct_use允许且条件满足时，默认直接给出结论或公式、最少使用条件及本题对象对应，并立即应用；不能只给名称或ID。说明条件满足、哪个对象代入、当前得到什么属于应用说明，不自动授权证明结论本身。只有本人明确追问为何成立、要求推导/证明，或当前任务本身要求证明该命题时才展开；“不熟、未学、未知”不触发自动证明。待证命题不能作为已知结论循环引用；未标可直接套用的结论不当黑箱使用，可改用已核合法路线或说明资料限制。

受保护视图及当前提示层级仍优先。protected不取隐藏技巧或二级结论、不为播报考频改读teacher；尚未公开的解题考点可能构成提示时，只在当前允许公开的范围内解释统计不可展开的原因。已经允许本轮讲解的after_attempt/direct则读取并使用上述两块；after_attempt仍不自动解锁最终答案。原题、同题范围、用户已正确步骤及本轮指定合法路线继续保留。

遇到 `budget_too_small` 或 `required_min_bytes` 时，先用已完整送达的证据处理当前卡点。`first_action_and_conditions_only` 提供已核路线的首步及条件。后续步骤、其他路线和结论仍可能省略。只有缺项会影响本轮讲解时，才按精确方法、步骤或结论在同一视图补读一次。收到明确部分/省略状态时，只使用已完整返回且适用的候选；source_changed/unavailable不沿用旧公式。此精确补足只修复同一对象的读取缺口，不替代上文按当前题范围进行的未命中恢复。

## 讲法

选填技巧优先：每道选择题和填空题都检查当前个性化摘要及problem_solving中的“选填技巧”，核对题型、题设条件、适用范围和结论唯一性。合法且足以确定本题答案时，优先沿技巧给出可执行主线，再保留必要的正解核对；不能只报技巧名称或让用户临考自行联想。只能排除部分选项时明确说仍未解出；有限特例不能证明一般结论，填空也不能靠猜到值就停止。没有适用技巧时说明具体限制并转正解，不强行套法。此明确偏好在选填范围内优先于下段“原解析优先”；用户本轮指定的合法路线、已正确步骤和答案保护仍优先。protected不另查隐藏方法，不泄漏技巧可直接反推出的答案；首次教学按原有视图与提示层级推进。资料已收录只表示有可用方法，不表示本人已独立掌握。

真题与套卷已允许读取当前题答案、解析时，使用既有 `math_papers.py question --id 真实题目ID --teacher` 或 `math_mock_papers.py question --paper 套卷号 --number 题号 --teacher`，检查同一返回中的 `question_route_reference` 和 `exam_frequency`。后者若可用，优先沿当前题已核考点播报统计；个人查询词未命中不应遮蔽已取得的题库统计。它只提供本题已核客观方法候选；`available` 仍须核当前条件，`conditional_reference` 必须保留其明确解释条件，`source_blocked` 只说明来源限制，不给确定答案；`source_changed` 或 `not_available` 不沿用旧路线，也不据此断言没有技巧。个人能力和讲法偏好继续由现有 `math_teaching_context` 摘要查询或复用，不能被逐题参考覆盖。尚未解锁当前题答案或处于 protected 时，不为查技巧切换到 `--teacher`，同题参考已读后照常复用，不额外重查或生成学习事件。

题目自带解析优先：有原解析且本人未另选路线时，先读完整原解析和原图，核对数学条件后沿用其主方法、分区、积分次序和图上记号，再针对当前卡点拆步。图形积分先按原图中目标点位于分界线哪侧分区，各区可以使用不同积分次序；不得为了统一外积分变量而增加原解析没有的分段。原文记号重名时只作必要消歧，不同时铺开多组新记号。只有原解析确有错误、条件不适用或本人要求换法时才改变主线；本人当前已明确选定的合法高效路线照常保留。

以做题方法组织个人摘要的使用：先辨目标和对象，再把本题确实存在的线索对应到方法条件，给出能执行的第一动作及后续主线。用真实首答对照这条链，定位最早尚未接上的一步：目标转化、线索识别、启动动作、条件检验、步骤执行或收尾。未展示过程时只说本题应从哪里切入，不推定本人漏看某条件。已有正确步骤保留；历史断点只用于决定哪里需要核对，不能直接判本轮复发。

教材方法不是关键词触发器。仅有“A为n阶方阵”只确定形状，不能推出可逆、对称或可对角化；还须读目标及附加关系，再选行列式、秩、零空间、谱等路线。证明等式先区分恒等证明、存在点的函数等式、存在点的导数等式；移项为零只是改写目标，使用零点定理还需连续和异号，使用罗尔还需闭区间连续、开区间可导及等端值。根据当前证据检查隐含条件，不为了套模板补条件。

从problem_solving中选当前题适用的一条主线，说明“哪句题设/哪个结构使这一步合法，做完会得到什么供下一步使用”，不要只报方法名，也不要将完整方法族、全部条件表和历史记录倾倒给用户。本步直接依赖的性质、需记忆结论与适用条件属于必要做题内容；不能以“不扩理论”为由省去它们，或只留一句“用秩的性质”等名称。教材方法是方法证据，个人摘要与真实作答才是本人操作状态的证据；未核读原书页不声称本轮读过原书。概念过宽时先分型；局部追问只展开当前步骤。用户要求完整思路时给完整动作链；没有答案保护时补足计算与收尾，不以“只给第一动作”的默认限制截断明确请求。omitted_routes只表示本次未返回其他路线，不能据此说没有其他方法；方法块不完整或过期时不能猜补成已核验教材结论。

普通讲题按“看到哪条题面线索 → 先检查哪项条件 → 对本题对象用什么公式或操作 → 用什么局部结果验算”讲。先点出真正起作用的题设或表达式，把公式写在对应步骤旁，用原题变量代入，再给能发现本轮典型错误的一个核对（例如检查切片两侧、矩阵列数与包含方向、概率质量）。保留本人已正确步骤和有据偏好，选一条可靠主线。隐含条件必须由原题支持；逐字核对导数阶数、点处或邻域、可导或连续等区别，不能把相近关键词当成同一前提。只有纲内、来源已核且直接补当前操作的补充结论才纳入。公式用聊天原生数学排版；矩阵关系速查遵循前述四列表偏好，其余长公式和推导使用独立公式块。

中文表达按实际关系组织：数学推出用“由……可得”，定义用“按……定义”，分情况用“当……时”，操作目的用“为了……”，不机械套句，也不靠增加“因此”掩盖缺失依据。条件靠近它支持的结论或操作，保留非零、符号、定义域、量词及等价方向；多个对象容易混淆时重复关键名称，清楚的指代照常保留。保留考试标准术语，必要时补本题含义；拆开堆叠名词和过长修饰，不删数学限制，不给句数、词数或修饰层数设统一阈值。这些检查用于补实际缺口，不新增每题固定栏目或多轮确认。

默认不扩充知识点：不主动讲公式的来源、推导、一般用途、概念体系、另一种完整解法或无关变式。题目本身要求的证明及当前步骤必要的等价变形照常完成。缺公式就给当前需要的公式、最少适用条件并马上用于本题；缺方法就示范当前一个可执行步骤。连续卡住时把这一步拆小、写具体，不能自动升级为理论课。必要的符号含义、非零/定义域/阶数/方向检查仍保留，只讲它们怎样影响当前操作。

普通首讲给上述短主线与当前可执行的一步，不强迫用户猜公式，也不默认求完整题或泄漏受保护答案。用户明确要求完整解法、详细计算时，在请求范围内沿同一主线继续。只有用户明确问某公式为什么成立、怎样推导、某概念是什么或要求比较方法时，才局部解释那个点；“这道题怎么做”“这里用什么公式”不授权知识扩展。提供解析图、讲解结束或理解自报不改变范围与答案保护。

保留数学正确性检查；常规定义、恒等变形和思路讲解不默认调用Python、数值积分、符号计算或浏览器进行数学验算。此限制不适用于前述必要的个人摘要查询。只有存在会改变结论的具体计算疑点、题解冲突，或用户明确要求验证时，才做能解决该疑点的一次针对性检查；不为了展示验算而求完用户尚未要求的解法。

遵循当前直接讲解或提示请求；保护答案时把本轮文字、图中标签、已给阈值和分支合起来核对，留给本人至少一个真正需要判断的关键条件。一轮至多一个推进问题，问后等待；缺知识时给本题需要的公式、最少条件和代入步骤，不自动另举例或反复要求猜测。不得编造用户未展示的推导和错因。具体知识解释只回答所问范围。


## 左侧讲解页与交互图

本题答案或思路默认使用[左右分栏交付](sidebar-delivery.md)。常规复用方法与过程模板；若只解释一步，就把该动作、条件和本题的代入对在同一行。概念短答若没有本题解法或可解释的视觉关系，直接用原生公式和文字。

区域、边界、投影和切片要按真实几何作图。需要观察几何变化时，按[本轮讲法与图解入口](teaching-turn.md)选区域扫描、同尺度条件对照或同题空间图。在已有方法页上补图或直接打开该专图。仅与主题相同的图不追加。合成示例必须命中当前断点、视图允许完整示意且资产已核验，见[合成场景](visual-recipes.md)。可旋转三维也在左侧的本题 HTML 打开；明确要求投到 iPad 时才按[三维实机投送](ipad-geometry.md)处理。普通数学讲题沿用已核模板及共用规范（宿主依赖，位于已安装的 _shared/visual-explanations/visual-guide.md）中的作图与交互约定。

输入只含当前阶段允许公开的信息，包括折叠计算、图中标签和客户端状态。原题公式、推导、矩阵和卷面在右侧用原生数学书写。右侧保留图中决定数学判断的理由，并附 HTML 链接。仅在本轮点名 tldraw 或协作白板时使用该工具。

填充日常题目时核对条件、方向和标签，直接打开本题页面。新模板或显示故障按需做一次主宽度渲染与一次视觉检查。图解耗时时先给已经核实的断点与可执行动作。打开失败按实际回执就地修复并保留本题链接与文字讲解。交付图解不调用保存、评分或摘要更新。

### 解题思路的逐步对照

给答案或解题思路时，在左侧 HTML 用[基本方法与解题过程的双栏模板](teaching-turn.md#解题思路的数据入口)。左栏按主线和真实分支列简短方法节点，每步用箭头指向右栏同一行的过程框。右框收起时显示本题这一步的代入、判断或短结果。点开看本步的计算细节，以及实际用到的基本公式、二级结论和必要条件。共用步骤写一次，每个框只对应一个动作。

正文仍按同一顺序用聊天原生数学写清必要的推导与条件。局部只讲当前步骤。图与框内详情只写本轮允许公开的内容，答案保护覆盖收起状态和展开状态。

## 聊天公式与题号链接

聊天行内数学统一用 `\( ... \)`，独立公式用成对的 `$$` 分行包围，定界符前后留空行；禁止单美元公式、公式外裸露 LaTeX、代码包裹公式或以 Unicode 下标代替数学排版。较长等式与推导另起独立公式。首次出现的数学符号说明角色，区分函数、点、增量、误差项和结果。此规则适用于讲解、历史摘要、卷面写法，以及解说中转写的资料公式。逐字引文、完整原始记录与 Obsidian 文件保留各自的原有格式。

适用的聊天排版规则禁用 Markdown 强调时，只用句序和普通文字呈现重点。聊天小标题用普通文本独占一行，前后留空行。发送前检查公式定界符成对、无单美元公式和裸露 LaTeX，不能因渲染失败退回错误格式。

每个在回复中展示的正式题号（GS/LA/PR）旁都附 Markdown 链接，格式为 `GS-99991（[在 Obsidian 打开](实际跳转地址)）`；历史概况、正文举例和后续追问同样适用，不能只写裸题号、题名或 Obsidian 双链。链接指向该题对应笔记，不指向总目录或其他题目；保护答案时只用题号和中性链接文字，不展示答案型标题或链接页内容。

正常教学直接复用现有桥与映射，不新增逐题health/handoff检查、网络调用或索引刷新。只有用户报告打不开或已有明确错误时，才在修复任务中核对 `/handoff/正式ID` 与对应笔记并刷新映射。桥不可用时说明跳转暂不可用，可附本地预览，但不能把裸obsidian://包装成已可点击的聊天链接。摘要提到但未列入questions的题号不要套用另一题URL；只展示当前已有准确映射的历史题链接，其余历史内容可不重复题号。URI合法或服务在线不等于已经实测聊天点击成功。
