# 本题明确请求的教学回顾

用户明确要求“保存并回顾”时，在保存前用已核同题资料给出回顾。单纯保存直接返回回执。按当前授权视图和题目选取以下内容。

教材回顾资格 `reference_ready` 与练习资格 `practice_ready` 分开。已核内容可以没有数一配题，但必须由回顾入口确认可作参考；不能直接读取归档原件绕过审核，也不能把可作参考当成可出题或可直接套用。已核一般结论仍须保留条件；同专题补充结论没有在本题使用时，明确其额外条件，不暗示本题已满足。当前待证命题不能作为已知结论循环调用。

### 三段内容

1. 基础公式：覆盖整道题实际调用的公式，以及用户在本题明确遗忘、请求列出且已经核实的公式，不能只总结最后一轮或最终解法。写全定义、等式和条件，保留本题需要的等价形式；求和写起点、通项、和值和收敛范围，微积分写变量及合法操作条件。例如本题使用了二倍角、降幂、几何级数和对数级数，就逐项给出相应公式，不能只保留最后拼出的半角等式。中间运算规则放在本段或方法相应步骤。
2. 二级结论：先给本题核心结论，再补同一小专题可直接迁移的关键结论，不扩成整章清单。每条写成“对象与条件＋完整结论或公式”，保留例外；“先取绝对值”“可以逐项积分”“端点单独处理”等操作提醒不能替代相应等式、适用区间和分支。若给和函数公式，明确原级数、闭式有效域及须另补的点。直接推论接在主条内，证明工具不拆成同级条目。
3. 解题思路：依据本题最后经核实的实际路线，简述“题面线索→条件判断→调用公式／结论→关键操作→检查”。保留本题为什么这样选法和步骤如何连接，不能只写“先求特征值、再求特征向量”等通用流程。它是独立一段，不能用方法步骤、参数分类或数值答案替代前两段，也不自动追加完整新证明或卷面。

第 3 段“解题思路”按[左右分栏交付](sidebar-delivery.md)在左侧打开本题 HTML，右侧保留三段文字、原生公式及该页链接。HTML 内沿用双栏对照。左栏是按主线和真实分支组织的思路树，每个节点用箭头指向右栏同一行的具体代入、计算或判断；右栏连续展示完整解题过程。点击右侧过程框展开该步的计算细节、实际用到的基本公式、二级结论和必要条件。正文按相同顺序说明每一步算什么、为什么这样做及怎样接到下一步。节点数量按实际解法确定；只覆盖已经讲解、核实且允许公开的范围，尚未完成的部分标出接续点。基础公式、二级结论仍分别按前两段完整交付。

复用图前核对其为上述双栏结构。新建或重做时调用讲题 Skill 的 [解题思路数据入口](teaching-turn.md#解题思路的数据入口)，传入 `method` 树及每步的 `process`、`calculation`、`formulas`、`conclusions`，按实际关系填 `children`。旧 `steps` 仅用于兼容既有横向图的原样重渲染，本轮新图和重做图使用 `method`。明确请求回顾时在保存前展示，单纯保存直接封存已有内容；日常填充不重写 HTML/MathML，仅打开本题 Codex 内置页面并读回左右位置，免去额外浏览器与截图验收，不为生成图重新读取个人历史。图生成失败时保留已成功的保存，先交付逐步文字并按具体错误补图，不重放 Capture。

用户提供或认可专题结论图、教材归纳或结论清单时，优先对齐其中的主题、条目范围、顺序和表述层级，核对数学条件后整理。不能凭自己的知识关联替换用户认可的主线；原件有错漏、截断或适用范围不足时明确修正或说明，不照抄错误，不猜补不可见原文。保留核心结论的完整含义，例如“公共特征向量”不能只改写成“B可对角化”而丢掉两者共用特征向量的关系。

“二级结论”段内按同一专题、条件与结论的逻辑次序编号，不再拆成多个含义重叠的小标题或卡片。

矩阵关系及同类二级结论，默认在相应段内合成“矩阵｜特征值｜对应的特征向量｜适用条件”四列表，短公式直接放入格内，条件逐行对应。保留基础公式、二级结论、解题思路三段及当前题范围，长推导仍用独立公式块。不要以纯文字说明表或原书截图替代这个已明确指定的展示形式。

用户要保留的是脱离本题仍能直接判断和调用的结论。每条先说明数学对象与必要条件，再写完整结论，最后按需要用一句话说明能用于何种所求。不能只报“相似性质”“秩一矩阵结论”等名称，不能省略公式的关键分支、重数、阶数、可逆或可对角化等前提。

以本题完整题面、已读解析和整段已核实的讲解与纠正为依据，采用最后经核实的版本。抽去只属于本题的数值与记号后，仍须保留结论成立所需的条件。用户猜测、已被纠正的助手说法和未解决争议不能写成成立结论。本题没有可独立抽出的二级结论时如实说明，已有标准方法放入“解题思路”，不强造定理。

以下示例说明用户需要的结论粒度。只在当前题实际涉及且已核实时选用，不逐题固定输出，也不将线性代数示例套到其他学科。

- 同时对角化（公共特征向量）。该专题可按四条组织，均保留A、B为同阶方阵的前提。第一条是AB与BA有相同特征值；第二条加A可逆，推出AB与BA相似；第三条在AB=aA+bB且数a、b满足ab≠0时，推出AB=BA；第四条在AB=BA且A在所讨论数域有n个不同特征值时，指出A的每个特征向量也是B的特征向量，并在同条补充可用同一P将两者同时对角化。此例不把“同特征多项式”或“比较对角矩阵乘积的元素”等更强补充或证明工具挤成独立主条目。
- 伴随矩阵的秩。设 \(A\) 为 \(n\ge2\) 阶矩阵，\(A^*\) 为其伴随矩阵，给出完整三分支公式。调用时比较 \(r(A)\) 与 \(n,n-1\) 的关系。

$$
r(A^*)=\begin{cases}
n,&r(A)=n,\\
1,&r(A)=n-1,\\
0,&r(A)\le n-2.
\end{cases}
$$

- 相似矩阵的性质。\(A\sim B\) 表示存在可逆矩阵 \(P\)，使 \(P^{-1}AP=B\)。列出本题用到的不变量，例如 \(r(A)=r(B)\)、\(\det A=\det B\)、\(\operatorname{tr}(A)=\operatorname{tr}(B)\)，以及特征值和代数重数相同。若用到矩阵变换，说明对同一多项式 \(f\)，有 \(f(A)\sim f(B)\)。
- 相似对角化与秩。适用前提是 \(A\) 已可相似对角化，此时 \(r(A)\) 等于按代数重数计的非零特征值个数。构造 \(P\) 的通用条件是其列为 \(n\) 个线性无关的特征向量，且列序与目标对角元顺序对应。
- 秩一矩阵。\(n\) 阶矩阵满足 \(r(A)=1\) 时，全部特征值为 \(\operatorname{tr}(A),0,\ldots,0\)，并且可相似对角化当且仅当 \(\operatorname{tr}(A)\ne0\)。保留迹为零时全部特征值为零的分支，不写成“必有一个非零特征值”。
