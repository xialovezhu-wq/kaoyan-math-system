# 数学讲解的左右分栏

每次给出某题的答案、解题思路或对某一步的实质纠偏，同轮在当前聊天的**左侧窗格打开本题 HTML**。右侧聊天照常写文字解答、必要条件和原生公式，附一个可以重开的普通 Markdown 文件链接。方法树、图、交互控件都在左页，聊天正文省去内嵌卡片、图片式解法、Mermaid 和 Visualize 标记。用户本轮明确指定其他形式时按本轮要求。

## 选取当前页

- 本题按[解题思路的数据入口](teaching-turn.md#解题思路的数据入口)渲染。一步答案用一个节点，提示只画已公开的这一步。同题同小问同公开范围复用本次任务的页面；纠正内容后更新并刷新。新题、小问或提示权限变化时用独立、题号和阶段可辨的文件名。工具给出的当前会话可视化目录是即时学习页的热目录。日终或已有复盘用其已核正式阅读路径。
- 需要看区域、切片、条件变化或旋转时，使用本轮获准的题图或专图；它可直接作为本题左页。要同时显示方法与专图时放在同一 HTML。已有合法的完整 HTML 直接打开。区域与合成场景渲染器返回片段时，可用下方 `math_sidebar.py` 补独立页面外壳。输入仅取本题当前视图的本机渲染结果。
- 纯展示未答题、只问一个诊断问题、只查定义、备题、保存回执和运维，按实际请求交付。若切回受保护阶段而旧页会泄题，先切至本轮准许的题面或收起本任务的旧解答页。先过滤再写 HTML，标题、链接文字、文件名、折叠项、脚本数据和 ARIA 与右侧文字同一权限。显示和点击不产生学习或评分事件。

## 在 Codex 桌面打开

用当次回执的 `open_in_codex` 在调用聊天内打开绝对路径，右侧保留 `html_link`。当前聊天所在显示器已获准作为侧栏交付位置。打开后用同一个 HTML 路径验证，文件名应唯一绑定本次聊天、题目、小问和阶段。

```sh
swift "<讲题Skill>/scripts/show_math_sidebar.swift" "<本题HTML绝对路径>" --current-page
```

该模式只操作已经实际显示此精确本地 URL 的唯一窗口，核对左页和右侧聊天同时可见才返回 shown。重写同题页后加 `--reload`。若仅返回 queued，勿宣称已显示。当前聊天内可先给唯一文件链接。已核对当前聊天标题时，用 `PAGE.html WINDOW_TITLE LINK_LABEL --current-chat` 打开这个窗口中唯一匹配的链接；它验证目标文件及左右位置。旧工作屏需要按具名窗口打开该链接时，仍可用 `--windows` 及 `PAGE.html WINDOW_TITLE LINK_LABEL`。T3 会话使用该宿主自己的学习分栏合同。

已有整页可用 `python3 <讲题Skill>/scripts/math_sidebar.py PAGE.html` 取得参数。给片段补独立外壳时同时传 `--fragment FRAGMENT --title TITLE`。
