# 五个合成数学场景

只从当前讲题命中的确切断点选一项。先看有界读取中的 `teaching_inputs.study_recipe`，它只提供已核资产的 ID、版本和哈希。确认用户正在区分下面对应的对象和条件后再出图。真实题如果换了函数、矩阵或随机变量，示例只传达关系，原题仍用确给条件和原变量。

| 场景 ID | 适合解释什么 | 同屏核对 |
| --- | --- | --- |
| saddle-sections-tangent | 把曲面截线和局部切平面混在一起，或不理解鞍点不同方向的曲率 | 同一曲面与原点，切换 x＝0、y＝0 和原点切平面。截线与切平面关系精确，曲面采样网格近似。切平面由该点的两项偏导得到。 |
| eigen-directions | 混淆共线与同向，或把零特征值当成零向量 | 同一组轴、同一尺度显示输入与输出。可验证正、负和零特征值，零输出用原点点标记，零输入单独作不合法示意。精确轴向和拖动近似分开。 |
| same-distribution-vs-independence | 从同边缘分布误推独立 | 切换同一次骰子结果和独立骰子，边缘分布一直保留。选格比较联合概率与边缘乘积，独立由全格成立来说明。表是精确理论概率。 |
| riemann-signed-area | 黎曼和中正负项抵消与几何面积混淆 | 比较中点矩形、带方向的积分与几何面积。 |
| gradient-direction | 混淆方向导数与梯度 | 对齐当前位置、单位方向和方向导数，梯度为零时相对方向未定义。 |

在数学运行根从现有视觉入口调用，使用当前题和子问的稳定标识、已有当前任务显示目录和当前授权视图。

```sh
python3 错题知识网络/scripts/math_teaching_visual.py \
  --recipe '<已核场景 ID>' --question '<当前题身份>' --focus '<当前子问或动作>' \
  --view '<当前授权视图>' --allow-geometry \
  --inline-root '<当前任务显示目录>' --output '<同目录>/<题号-小问-阶段>-example.html'
```

仅允许已核的 `after_attempt` 或 `direct`，尝试后仍要确认该层级能展示整个示意。保护视图只给已公开题面。题目公式、原生推导及必要条件继续写在聊天正文。

“驻点不一定是极值”先说明可微、内点与必要条件的方向，再用此处的鞍面反例。渲染时绑定当前题号、焦点和视图。已有方法页用 `render_math_flow.py --figure` 接入刚返回的片段；单独看图时用本 Skill 的 `scripts/math_sidebar.py <本题页.html> --fragment <刚返回的片段> --title <当前小问标题>` 生成独立页。按[左右分栏](sidebar-delivery.md)操作回执的 open_in_codex，在当前聊天左页打开。这样切换截面时，“这一步为什么？”会随所选方向解释正负号，切平面一步解释必要条件的逆命题。

追问可复制 `math-scene-question-v1`。其中 scene_id、scene_version、instance_id、state_version、scope（question_id、focus、view）、parameters 和 user_question 共同指明当时的画面。手工粘贴只说明复制时的状态；换题、换视图、刷新或改变截面后重新取得对应状态。只有当前身份、实例、授权范围和版本可核对时，才把它作为当前画面解释；已有同题教学材料直接复用。未绑定题目的独立参考页只支持解释合成示例。T3 自动传回由共享层维护，复制和拖图不写学习记录。

Gram–Schmidt 的投影扣除和归一化适合解释“正交”和“单位化”的区别。仅当该步是当前卡点时，按现有图解入口展示；分数输入先按原题作精确运算，演示页用数值校对。参考实现以 `parseFloat` 读取分量，不能把 `1/2` 当作已解析的二分之一；内积绝对值小于 0.0005 的零色、三位小数显示，以及参考向量模平方小于 0.000000001 的保护阈值，都属于数值显示或计算约定。正交性按原向量的精确内积判断。[参考实现](https://github.com/teorth/tao-web/blob/f15a1cdf7c6c01e8e5f166e5c1048022b21f2806/static/apps/gram-schmidt.html)

稳定离线文件与校验清单在数学根的 `错题知识网络/assets/math-study-recipes/`。场景参数、授权视图、数学状态和来源哈希随原入口核验。观看、拖动与看懂只作当时反馈，独立作答须有本人实际展示的步骤；图解本身不触发保存。用户明确授权时原 HTML 可按现有附件合同封存。
