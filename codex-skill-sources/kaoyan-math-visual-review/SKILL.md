# 数学晚间错题复盘

项目根目录与迁移定位见[本机路径](../kaoyan-math-question-worker/references/local-paths.md)。以指定学习日为准，复用该日已核的 Capture、题面、解析和正式结果。尚未正式入库但已核实的同日学习也可复盘。按原题及实际小问覆盖，同次补充并回原题，跨题的相同结论可复用。确需核条件时回教材或已核原解。

## 每道题的记忆卡

按[卡片结构](references/output-structure.md)输出，知识点写在短标题中。题面用清晰原图或结构化图表，保留完整条件、选项与小问。题面下方依次紧接：

1. 二级结论：每条给可直接复用的结论或等式，同时写必要条件和例外。没有独立结论就省去额外推论。
2. 基本方法与解题过程。保留方法树的先后和真实分支。一节点对应一步，在右边用箭头连到一个过程框，填该题在这一步实际用到的条件、代入、推导或判断。继续到每个小问的结论。
3. 基本公式：列本题实际调用的定义、恒等式或公式，带必要符号角色和使用条件。

以公式、短标签和逐步计算为主。默认省去作答流水、错因长段、重复详解、口播全文和测验。需要时只留一句会影响做法的提醒。保留答案保护，学习过的原题可以展示。当前未解锁的题只给获准的题面和内容。

公式与二级结论优先使用当前已核公式卡：条件和边界与公式同屏，推导与来源按需展开。确需图时优先用本题同身份、同阶段、经检查的几何投影。10–15 分钟日终口播仅在明确要求时编写，作为独立讲稿。

## 聊天和 HTML

普通“今晚复盘总结、睡前复盘、整理今天知识点”直接给阅读卡。用最小文本树或 Mermaid 标识方法步骤，按相同步骤在聊天正文给对应过程和原生公式。明确要求 HTML、日终交付 HTML 或修正点名的复盘页时，按[HTML 模板](references/html-review-template.md)生成或原址更新，验回原题、公式、逐步连线和导航。先核定 T9 过程目录，再生成过程件，保留需替换的旧页面。

[写入和证据边界](references/safety-boundaries.md)适用于两种成果。阅读卡不生成学习、评分、正式入库或掌握记录。明确要求先入库转 [nightly-qa](../kaoyan-math-nightly-qa/SKILL.md)，次日选题转 [warmup](../kaoyan-math-warmup/SKILL.md)。只有明确要求问答、测验或独立复盘才走 [independent-review](../kaoyan-independent-review/SKILL.md)。普通模式由当前代理执行。
