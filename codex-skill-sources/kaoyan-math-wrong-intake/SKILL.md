# 数学快速保存

沿用用户当前模型。正常路径只有当前题完整保存，不查个人历史、不分析错因、不评分、不重建索引、不调用其他模型或MCP。

用户等待以10–20秒为目标，尽量十几秒内完成，从保存请求到成功回复计算；脚本耗时不能代替真实对话的端到端验收。同会话已读过本Skill且没有更新信号时直接复用，不重读Skill、跑help、翻旧包或源码找示例。prepare返回后直接按下面模板保存，题号精确匹配由保存脚本完成，不另行搜索题号或旧包。当前回答需要礼花时按讲题Skill直接调用一次官方工具，不搜索MEMORY重新找规则；礼花不是保存前置条件。

复用讲题阶段留下的题目身份、当前session、起始消息位置、附件角色与卷面位置。参数齐全直接保存；缺少位置或图片路径时只执行一次准备入口：

日志路径未知时省略--rollout，脚本按当前session-id只读查询应用状态数据库，并核对日志身份；不使用find全目录搜索。已知路径仍可传入。prepare返回的save_args包含已确认日志、会话、结束行及已传入的起点，直接复用；起点为null时只从返回消息中选择本题起点。不得把其他任务或本侧聊的ID当主线程ID。

```sh
python3 数学一回滚复习系统/scripts/capture_current_math.py prepare \
  --session-id 当前会话ID
```

已知本题起点可追加 `--start-line 本题起始行`。返回当前任务可见消息的行号、预览、图片原件路径、卷面候选和每条用户消息对应的稳定attempt。根据本题已知上下文选择精确起点、卷面和图片角色；候选不等于已确认卷面，不能靠“最后一张图”猜题目边界。默认只看最近100条可见消息；明确窗口不含本题起点时，用已有起点扩大当前任务范围，不搜索其他任务或旧包。

```sh
python3 数学一回滚复习系统/scripts/capture_current_math.py \
  --rollout 当前任务日志 --session-id 当前会话ID \
  --start-line 本题起始行 --end-user-line 准备返回的结束行 \
  --source-question-id 原始题号 --date 原学习日期 \
  --solution-line 已确认卷面行 \
  --image-role 起始行:题图块号:question_image \
  --image-role 起始行:解析图块号:explanation_image
```

已有正式ID用 `--formal-id` 替代 `--source-question-id`；无印刷题号用稳定 `--source-locator`。精确身份查询只用准备好的索引；零匹配按new_source，冲突或缺索引明确返回缺项，不能试写正式卡发现身份。题号按题图中明确的来源ID传入，例如ID:79993；另一个章节编号保留在原始题图与对话中，不拼接成猜测的索引键。

--solution-line是prepare返回的1起算日志物理行号，指向包含已展示卷面的整条assistant消息。脚本把该消息全部文字原样保存为solution_text，即使其中也有纠偏和解释，这也是预期行为；不需要裁剪、另写干净版本、重复展示或再查help。仅提到“卷面写法”但未实际给出卷面的消息不是有效候选。

卷面在本次保存请求之后才展示时，使用 `--solution-line current` 替代数字行号，省略 `--end-assistant-line`，并保留prepare确认的 `--end-user-line`。脚本直接选取该请求之后唯一一条非空、可见的assistant消息，将其全部文字原样封存并自动延长会话边界；跳过推理、工具调用、事件副本和空消息，遇到新用户消息或多条候选就报错。该参数是调用者对刚展示消息作为卷面的明确选择，不自动判断内容是否为完整解答。

先完成必要的prepare，再把本轮纠偏和卷面合在一条可见消息展示，紧接着用current直接保存。不要为寻找刚展示的卷面再执行grep、rg、awk或第二次prepare，也不要输出单独的空泛进度消息造成多个候选。已有已确认卷面行号时沿用数字行号，不重复展示；多条消息的特殊情况只使用已有确切行号，缺少时按明确的边界错误处理，不猜测或反复搜索日志。

没有完成的卷面则省略solution参数，不凭空生成。本题完成且答案已解锁时，由讲题Skill先展示卷面；保存层只引用原文，不重写或重复展示。块号从0开始；图片角色沿用讲题时已确认身份，不按顺序猜。脚本直接读取本地图片或紧邻image包装声明的原件，不必手写映射JSON。非标准附件或缺件仍使用已有 `--artifacts-json`，不得为提速省略原件或缺件声明。

结束行已由prepare确认时直接使用该行；参数齐全且没有新用户消息时可省略end参数使用auto。attempt默认由session和本题起点确定，重复请求保持同一起点；已有包或旧attempt必须传原 `--attempt-id`，不能换成auto制造第二份记录。所有相关用户/助手文字、题图、解析、作答图和卷面逐字保存。SVG直接保存原件，缺附件如实标记。

晨间五题、普通warmup及C题都直接附上已知 `--queue-id` 和 `--item-id`，无评分事件时省略 `--score-event-id` 与 `--score`；队列身份不依赖评分。普通题可省略队列参数。仅需引用一个已经存在且可验证的历史评分时，传原 `--attempt-id` 与 `--score-event-id`，不能先补评分或重试评分来满足保存。旧评分引用失败时保留原件与明确缺项，交正式处理或单独修复；不在当前学习中读源码追查。更新表述用 `--requested-action update_representation`；用户要求标记掌握用mastery_candidate，仅保存请求而不宣称掌握。

正常路径为一次保存，缺参时为一次prepare加一次保存。成功只认本次写入回执，必须为stage/record recorded或noop、formal_write_count=0、score_write_count=0；回执已含包号、事件ID、消息数和耗时，成功后立即结束，不再打开manifest、conversation、solution文件逐项复查。用户要求下一题时，保存后直接交回已预处理的下一题。不追加整日verify、源码阅读、历史查询、夜间整理或归档。失败保持原包，依据明确错误修正输入后重试相同身份；不能为赶时限宣称成功或跳过完整性检查。补充同一已保存事件的材料按 [补充与人工恢复](references/manual-capture.md)，不另算复发。

成功后一句话：`快速记录成功，完整会话包已保存，待正式入库；你可以继续下一题。` 附一个本次包链接即可，不展开包内清单。

仅日志不可读、精确边界无法建立或同事件补充时读人工参考。明确要求现在正式入库才转正式Skill。B独立复盘不调用此Skill。
