# 数学 LongMemEval-V2 验收

## 固定范围与部署门槛

在查看响应之前固定同一版正式原生索引、10 个真实查询和 20 个证据检查项：事实、变化、方法、易错点、前提辨析各 2 个查询。开发边界用不同来源组的隔离合成数据。相同知识点、当前操作、after_attempt 视图与预算对比。初次请求：两版 20/20 对的正文逐字节相同。另用同参数、同版本重读，4500 字节组有 7/10 由原来返回 `unchanged` 改为保留原正文及缺项；完整响应仍能命中。未为这些结果更改检索内容、用户记录、教学模型或预算。

| 类别 | 12000：两项都具备 | 4500：两项都具备 |
| --- | ---: | ---: |
| 事实 | 2/2 | 1/2 |
| 变化 | 2/2 | 2/2 |
| 方法 | 2/2 | 0/2 |
| 易错点 | 2/2 | 1/2 |
| 前提辨析 | 2/2 | 1/2 |

合计分别 10/10 和 5/10。必要证据单项分别为 20/20 和 13/20；基线和候选同分。少字节时方法或返回路径可省略，不能把留在短摘要中的部分信息当完整公式或条件。个人变化两案的实际原件、哈希与用户/提示顺序均核对。教材及参考使用本机可用方法源，未逐条重做全库教材页审核，也未将来源标签本身计作语义支持。日常模型全量最终作答正确率未测；此前同两案的仅当前题、旧记忆和重审记忆内容对照保留，不能视为新的独立盲评。

## 查询时间

在同一机器和同一索引执行 160 次完整读（每版每个预算 10 次新进程、30 次热进程），0 超时、0 失败、0 越预算。新进程组含启动开销，未清理系统页缓存。固定门槛为候选 p95 不高于基线 p95 的 110% 与基线 p95 加 50 ms 两者中的较大值。p95 使用近秩；ms 四舍五入。

| 预算与进程 | 基线 p50 / p95（ms） | 候选 p50 / p95（ms） | 结果 |
| --- | ---: | ---: | --- |
| 12000，新进程 | 196.1 / 321.6 | 218.2 / 270.7 | 通过 |
| 4500，新进程 | 195.3 / 279.8 | 218.2 / 271.9 | 通过 |
| 12000，热读 | 30.3 / 75.0 | 33.2 / 164.3 | 首次超标；交错配对复测 30+30 次，p95 87.6 / 73.5 ms，未复现回退 |
| 4500，热读 | 33.4 / 88.3 | 37.0 / 108.2 | 通过 |

首段实质解释及完成整段模型回复的时间未测。不能拿查询时间或启动时间替代。安装后做正常讲题单次读回，实际个人概况与选定快照一致；另读保护、直接讲解、紧预算同版重读、历史截点。对本机已授权案例完成一次基于实际收到正文的解释核对；没有把这次核对写成用户练习或掌握证据。

## 关键用例与正式整理证据

| 用例 | 实际检查 |
| --- | --- |
| M01 抵消 | 通过精确键读到“先定位抵消，再展开至首个未消失项”的整条方法；手核正弦三阶项。旧同名查询存在候选超上限的未匹配情况，精确键可用。 |
| M02 前提 | 实测联合正态与两个正态边缘分开；用随机符号乘以原正态变量的反例核对。 |
| M03 更正 | 合成旧错误在更正后不作当前依据；跨代原话及来源绑定丢弃，未泄漏。 |
| M04 提示与独立完成 | 两次合成学习分开；提示后改答不提升独立掌握；后来的独立范围不扩大。 |
| M05 迟到与时间 | 历史获知条件和实际发生时间分开，另做真实截点读回。 |
| M06 多依据与预算 | 对照同一版本两种预算，验证省略回执、实际返回指针、缓存不掩盖缺项。 |
| M07 隔离与保护 | 本机三视图、合成题卡标题和 stale 诊断不泄漏；不会回退到全库读。 |
| M08 发布与恢复 | 失效、不同时间和维护重试由真实入口的隔离故障用例覆盖；无复写学习事件。 |
