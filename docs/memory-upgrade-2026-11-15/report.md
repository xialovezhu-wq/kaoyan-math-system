# 数学记忆：LongMemEval-V2 增补

本轮改动已在本机启用。它解决两个实际读取问题：有缺项的响应不能被同版命中当作完整正文；原话索引与原生索引换代时，不把旧代的原话及其句柄装进新代的回答。原生讲题仍使用原入口、读同样的本机预生成数据、沿用原视图和字节预算。验收可选用 `--audit-context` 记录最终送达的证据、大小与哈希。缓存完整命中的行为保留；受保护状态下不返回可能带答案的题卡路径。

## 来源与覆盖

[LongMemEval-V2 v1](https://arxiv.org/html/2605.12493v1) 区分检索收集证据和固定 reader 作答。本项目据此单独验收实际返回的上下文、答案保护和查询时间，并将五类能力映射为数学事实、变化、方法、易错点、前提辨析。这里的数字只适用于本次数学样本，不是论文结果或学习效果。

| 条款 | 现状和本轮变化 | 验证或边界 |
| --- | --- | --- |
| LM-01、02、04、05 | 保留原题、真实作答、提示与正式接受链；知识结论和个人表现分开；先核当前题条件与本轮作答，再使用同点历史。 | 原案例已回核原轮次；本轮不新写历史、经验卡或掌握度。 |
| LM-03、08 | 既有事件时点和正式接受时点、来源哈希、维护版本与同批恢复保持有效。补原话／原生索引跨代拒绝。 | 新增换代测试；本机回放拒绝把后收录的个人摘要带回历史截点；恢复测试使用独立的合成账本。 |
| LM-06、07 | 审计和来源核查集中在维护及验收。讲题不加线上检索调用；普通现读不再为无原话请求做额外索引版本查询。有缺项不返回完整缓存命中。 | 固定 10 个真实查询、20 个证据检查项；两种预算分别计数。未全库复审。 |
| LM-09 | 保留三种原视图、原题隔离；受保护视图不返回精确题卡路径或过期诊断中的文件名。 | 真入口读回及泄漏模拟；公开适配版也屏蔽旧身份中的题卡路径。 |
| LM-10 | 查询、实际教学解释、正式维护分开。验收开关不进入日常工作流；没有新定时任务。 | 160 次完整读分别统计；另核同版重读。整段解释和此次新维护耗时未测。 |

原 A 准备、接受、纯语义维护、跨分包汇合、B 后审和 C 发布按原合同。复核当天已有的一份正式批次：两种能力都被用于真实业务，有服务端请求 ID、输入输出哈希、usage 与下游证明。维护证据及边界见 [验收](acceptance.md)。
